Je dagboek in Supabase

Log in op je dagboekaccount. Dit is een gebruiker binnen je Supabase-project, niet je Supabase-dashboardaccount.

Je bestaande dagboek wordt eenmalig omgezet. Daarna heb je alleen het wachtwoord hierboven nodig.

Eén wachtwoord voor inloggen en ontsleutelen. Wijzig het via deze app; een reset buiten de app ontsleutelt je bestaande berichten niet.

Eenmalig instellen: voer supabase-schema.sql uit in de SQL Editor van dit project. Daarna kun je hier een account maken en inloggen.
